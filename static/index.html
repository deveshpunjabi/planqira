❓ Questions & Answers

Frequently Asked Questions

Everything you need to know about Planqira’s financial integrity, cognitive models, and offline operations.

Why does Planqira calculate in integer paise?

Standard floating-point numbers in JavaScript and Python suffer from IEEE-754 precision drift (such as 0.1 + 0.2 producing 0.30000000000000004). In wedding and commercial budgets totaling millions of rupees, rounding errors accumulate into contract disputes. Storing and calculating in integer paise (₹1 = 100 paise) guarantees penny-perfect accounting.

Which Google AI models are supported?

Planqira natively integrates Google DeepMind’s latest Gemma 4 models (gemma-4-31b-it and gemma-4-26b-a4b-it) as well as Gemini Flash. Model selection is dynamically configurable via the GEMINI_MODEL or AI_MODEL environment variables without code modification.

What happens if no API key is configured or quota fails?

Planqira is completely resilient. If the GEMINI_API_KEY is missing or quota is exhausted, the system automatically falls back to an internal heuristic parser with a transparent is_simulated: true flag. The user is never blocked or left with a broken UI.

How does quote approval prevent double counting?

When a vendor quote is approved, Planqira atomically searches for existing estimated line items in that category (e.g. Catering). It marks the estimated item as REPLACED and supersedes it with the exact contract quote line item, preventing costs from being counted twice.

How does non-destructive scenario reversion work?

Unlike destructive rollback scripts that drop database rows, Planqira creates a fresh forward revision (e.g., reverting v2 to v1 produces Scenario v3). It restores line-item states while strictly preserving settled payment records, task history, and audit trails.

Can Planqira be deployed to Vercel and GitHub?

Yes. The codebase includes a native vercel.json and ASGI serverless entry point (api/index.py) running standard Python runtimes. The entire repository footprint is strictly under 1 MB, ensuring lightning-fast CI builds.
